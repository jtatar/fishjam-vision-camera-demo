# Showcase media

- [`demo.mp4`](demo.mp4): a 23-second, silent H.264 video at 1280×720. The publisher and viewer share the original timeline.
- [`preview.png`](preview.png): a still from the video.

The showcase is cropped from a single desktop recording, framed with the [recording scene](../recording/scene.png), and trimmed before the session ends. It does not retime either device or remove the stream's delay. The original stays local; the compact export is checked in alongside the source.

The README also embeds the video through a GitHub attachment for inline playback. To make another take, follow the [recording guide](../recording/README.md).
